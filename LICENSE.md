## 🛠️ Troubleshooting Common Issues


*   **Error: Injection Failed**
    *   **Description**: The module fails to initialize after execution.
    *   **Solution**: Run the execution environment with administrator/root privileges and verify compatibility with your platform version.


*   **Error: Visual Artifacts or Lag**
    *   **Description**: Significant performance degradation when enabling visual overlays.
    *   **Solution**: Reduce the maximum render distance and disable non-essential ESP elements.


*   **Error: Connection Timeout**
    *   **Description**: Frequent disconnections during active sessions.
    *   **Solution**: Increase automation delays and adjust smoothing to mimic more natural behavior patterns.


*   **Error: Configuration Not Saved**
    *   **Description**: Settings revert to defaults after application restart.
    *   **Solution**: Ensure the application has proper write permissions to its configuration directory.
